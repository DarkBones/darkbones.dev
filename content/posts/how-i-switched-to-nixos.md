# Scratchpad

## Steps I followed

## 1. Master the Nix Package Manager

### 1.0 Install the Nix package manager

Install with command:
```
curl -L https://nixos.org/nix/install | sh -s -- --daemon
```

### 1.1. Follow the guide

Go through guide here: https://nix.dev/tutorials/first

It will teach you about some basic ad-hoc commands. My epiphany when going through the guide: Holy shit, I can configure my next system while still on my current, working system.
